Ruru

Ruru 可以更改你的 Bose 耳机的设置，电脑和手机上都能用。

它是免费的。不需要账号，也不联网。

使用方法

  1. 为你的电脑或手机下载 Ruru。
  2. 像平常一样，通过蓝牙连接你的耳机。
  3. 打开 Ruru。它会找到你的耳机，并显示耳机的设置。

第一次打开

Windows 和 Mac 第一次打开时可能会发出警告，因为 Ruru 还没有 Microsoft 或 Apple 的签名。

  • 在 Windows 上，选择“更多信息”，再选择“仍要运行”。
  • 在 Mac 上，打开“系统设置”，进入“隐私与安全性”，然后点按“仍要打开”。在 macOS 12 上则是“系统偏好设置”，再进入“安全性与隐私”。

如果 Windows 提示 Smart App Control 拦截了 Ruru，那么 Ruru 无法在那台电脑上运行。Smart App Control 只允许运行已签名的应用。

请先关闭 Bose 应用。同一时间只有一个应用能与耳机通信。

能更改什么

  • 聆听模式，以及你自己的模式
  • 降噪的强度
  • Wind Block 和 Immersive Audio
  • 低音、中音和高音
  • 快捷按钮的功能
  • 自我语音、多点连接、自动关机等

在电脑上，Ruru 会待在时钟旁边的角落，并显示电量。

Ruru 不会更新耳机的固件。固件更新请用 Bose 应用。

隐私

Ruru 只与你的耳机通信，不会向任何地方发送任何内容。

没有账号，没有跟踪，也没有崩溃报告。Android 版应用完全不能使用互联网。

本网站没有 Cookie，也没有跟踪。它只会向 GitHub 查询哪个版本是最新的。
